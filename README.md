## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/bvhithesh012/Personal-Portfolio.git
```

Navigate to the project directory:

```bash
cd Personal-Portfolio
```

Install dependencies:

```bash
pnpm install
```

Run locally:

```bash
pnpm run dev
```
