=================================
IMMERSIVE 3D EXPERIENCE REQUIREMENTS
=================================

This must NOT be a normal portfolio website.

The entire website should feel like an interactive futuristic 3D experience.

Every section should contain motion, depth, interaction, and storytelling.

Use:
- Three.js
- React Three Fiber
- Framer Motion
- GSAP ScrollTrigger
- React Spring

=================================
SCROLL ANIMATIONS
=================================

As the user scrolls:

- Elements should smoothly reveal themselves.
- Cards should float into view.
- Sections should transition like scenes in a movie.
- Background objects should move with parallax effects.
- The camera should subtly animate through the experience.
- 3D objects should rotate and respond to scroll position.
- Text should animate with staggered reveals.
- Project cards should emerge from depth.
- Timeline items should animate progressively.
- Skills should orbit around a central node.

Scrolling should feel like exploring a futuristic digital world.

=================================
CLICK / TAP INTERACTIONS
=================================

When users tap or click elements:

Skills:
- Expand into detailed skill panels.
- Trigger glow effects.
- Display proficiency information.

Projects:
- Open immersive project showcases.
- Expand into fullscreen project presentations.
- Display project architecture and tech stack.
- Animate project mockups.

Certificates:
- Open certificate viewer modal.
- Zoom animation.
- Fullscreen preview.
- Download option.

Buttons:
- Ripple effect.
- Glow animation.
- Magnetic hover interaction.

Social icons:
- 3D rotation.
- Particle burst effect.
