PROJECT INTERACTION EXPERIENCE
=================================

When a project card is hovered:

- Card lifts in 3D.
- Spotlight effect follows cursor.
- Repository icon glows.
- Project preview animates.
- Display "Click to Explore Project" message.

When tapped on mobile:

- Card expands slightly.
- Shows project details.
- Displays GitHub action button.

Desktop Experience:

- Hover reveals repository information.
- Click redirects to GitHub.

Mobile Experience:

- Tap once shows project details.
- Tap again opens repository.
